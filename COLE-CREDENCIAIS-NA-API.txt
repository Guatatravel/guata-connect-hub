============================================

Este arquivo está no PAINEL (guata-connect-hub).
As credenciais NÃO vão aqui — vão na pasta IRMÃ da API.

PASSO A PASSO NO WINDOWS:
1. Abra o Explorer (Win + E)
2. Cole este caminho na barra de endereço e Enter:

   C:\Users\guilh\bot\guata-channel-api

   (Se não abrir, tente procurar pasta "guata-channel-api" em Documentos ou bot)

3. Clique com botão direito → Novo → Documento de texto
4. Nomeie exatamente:  .env
   (Windows vai avisar "quer mudar extensão?" → Sim)

5. Abra o .env com Bloco de notas e cole o conteúdo abaixo
6. Salve e feche

7. Reinicie a API: na pasta guata-channel-api, terminal: npm run dev
